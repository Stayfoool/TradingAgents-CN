# 重大信息源覆盖评估笔记

日期：2026-05-29

## 目标

评估 TuShare、AKShare 这类开源/轻量数据源是否足以覆盖对股价影响很大的信息，并为后续选择 Wind、Choice、iFinD 或专业新闻源提供验收依据。

## 判断口径

重大信息分两类：

- 结构化数据：行情、财务报表、公告列表、股东增减持、机构持仓、交易日历等，可按字段直接入库和校验。
- 非结构化事件：季报超预期、盘后股价异动、公司业务数据披露、券商研报观点、权威媒体报道、产业资本减持等，需要新闻/公告/研报文本和事件抽取。

不能因为一个数据源有新闻接口，就认为它能稳定覆盖所有重大事件。必须按事件类型、市场、来源、权限、时效性分别验收。

## 样例事件

### Dell Technologies 季报与盘后异动

事件：2026-05-28，Dell Technologies 发布截至 2026-05-01 的 2027 财年第一财季报告，中文媒体报道其盘后股价一度大涨近 40%，市值约 2059 亿美元。

覆盖判断：

- TuShare：有美股行情和美股财务指标等接口，也有新闻快讯接口；但 Dell 季报盘后暴涨这类信息是否可及时入库，取决于美股数据权限、新闻权限和中文资讯源是否转载。不能只依赖 TuShare 普通 A 股数据权限。
- AKShare：有美股行情相关接口，也有财经快讯/新闻接口；但 AKShare 没有统一的资讯覆盖承诺，不能保证及时抓到盘后美股财报和异动原因。
- 更合适来源：公司 IR、SEC/8-K/10-Q/earnings release、交易所/行情源盘后报价、Bloomberg/Reuters/FactSet/Wind/Choice/iFinD/Benzinga 等。

### MiniMax 业务数据披露

事件：2026-05-28，MiniMax 披露全球企业和开发者客户数、全球用户规模等业务数据。

覆盖判断：

- TuShare/AKShare 可能通过新闻文本间接出现，但一般不是结构化字段。
- 如果披露来自公司官网、公众号、媒体采访、券商研报或港股公告，TuShare/AKShare 都可能漏掉。
- 应作为非结构化事件情报处理，需要来源链接、发布时间、原文摘要和多源交叉验证。

### 大基金减持芯片相关股票

事件：2026 年以来，国家集成电路产业投资基金减持半导体相关公司，部分信息来自上市公司公告、港交所权益披露和媒体汇总。

覆盖判断：

- TuShare：A 股上市公司公告和股东增减持等结构化接口可能覆盖一部分 A 股公告；港股减持、中芯国际 H 股权益披露、媒体汇总和解读需要额外权限或其他来源。
- AKShare：可从东方财富、巨潮、公告大全等接口覆盖一部分公告和新闻；但跨 A/H 股、港交所披露、媒体汇总和产业链解读不能保证完整。
- 更合适来源：交易所公告、港交所披露易、上市公司公告、Wind/Choice/iFinD 的公告与股东持股变动库、权威财经媒体。

## 数据源选择结论

TuShare 和 AKShare 可继续作为行情、基础数据、部分公告和部分新闻的低成本来源，但不能作为重大决策信息的唯一来源。

第一阶段推荐：

1. 行情和基础数据：TuShare 主源，AKShare 兜底。
2. A 股公告和结构化减持：TuShare/AKShare 先接入，但必须对账交易所公告。
3. 美股财报和盘后异动：必须接入美股专用新闻/财报/盘后行情源。
4. 研报、机构观点、产业链事件：优先评估 Wind、Choice、iFinD。
5. 事件抽取：所有重大事件必须保留来源、时间、原文链接、供应商、置信度和交叉验证状态。

## 验收规则

每个候选信息源至少用以下样例回测：

- Dell 季报盘后大涨：能否在北京时间次日开盘前抓到财报、盘后涨幅、AI 服务器指引和权威媒体报道。
- MiniMax 业务数据披露：能否抓到公司披露原文或权威媒体转载，并抽取客户数、增长倍数、用户规模。
- 大基金减持芯片股：能否抓到公告原文、减持主体、标的、数量、金额、日期、A/H 股市场和媒体解读。

如果某数据源只能覆盖其中一部分，应在系统中标注 `coverage_gap`，不能让模型把缺失信息当作不存在。
