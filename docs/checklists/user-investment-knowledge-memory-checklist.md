- [ ] 审计模型检查规则是否真实存在。
- [ ] 审计模型检查规则是否仍在有效期内。
- [ ] 审计模型检查当前数据是否满足触发条件。
- [ ] 审计模型检查模型是否篡改用户规则含义。
- [ ] 规则冲突时输出冲突说明。

## 复盘成长

- [ ] 规则触发后记录触发上下文。
- [ ] 自动计算触发后 1/5/20 日收益。
- [ ] 输出规则结果标签：`helpful/harmful/inconclusive`。
- [ ] 每周生成规则复盘报告。
- [ ] 规则置信度调整有记录。
- [ ] 重要规则变更需要用户确认。

## 残余风险

- 用户经验可能只在特定市场阶段有效，必须设置有效期和复盘。
- 行业标签不准会导致规则误触发或漏触发。
- 没有足够行情和新闻数据时，模型可能错误判断规则是否满足。
- 规则过多会污染上下文，需要限制每次注入数量并按相关性排序。
