## 残余风险

- TuShare 账号真实权限未确认前，不能运行全市场高速初始化。
- AKShare 没有统一官方频次配额，底层站点可能返回空数据、拒绝访问或临时变更字段。
- Wind 公开资料能确认其存在 API 和多语言/多系统支持，但具体权限、频次、云服务器使用和落库权利必须以合同及技术支持确认为准。
- Wind 历史补库和 TuShare 增量混用会产生复权口径、单位、交易日历和停牌处理差异，必须通过对账脚本控制。
- 最近 3 年日线足够支持监控第一阶段，但不足以做长周期回测和完整周期研究。
- 新闻、公告、券商研报属于另一类数据权限，不应被历史行情初始化任务覆盖。
