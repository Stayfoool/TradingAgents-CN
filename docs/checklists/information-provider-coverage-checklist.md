## 字段要求

- [ ] 所有重大事件都保存来源名称。
- [ ] 所有重大事件都保存原文链接或公告链接。
- [ ] 所有重大事件都保存发布时间和采集时间。
- [ ] 所有重大事件都保存供应商标识。
- [ ] 所有重大事件都保存结构化抽取结果和原文证据。
- [ ] 所有重大事件都保存交叉验证状态。
- [ ] 覆盖不足时输出 `coverage_gap`，不把未抓到的信息解释为不存在。

## 残余风险

- TuShare/AKShare 有新闻或公告接口，不代表能稳定覆盖全部重大事件。
- 美股盘后异动、公司 IR、SEC 文件、研报观点、港交所权益披露通常需要专门数据源。
- 媒体转载存在延迟和漏报，不能替代公告原文和交易所披露。
- 不同供应商对同一事件的时间、标题、金额和股票映射可能不一致，需要对账。
